Windows

For your own Windows account

Download for Windows

Setup program

Windows may show a SmartScreen warning when you run it: here's why.

Run it and choose a Start Menu entry, a Desktop shortcut or starting when you sign in. It installs under your own account unless you pick another folder. A newer one updates it; the same one repairs or uninstalls it.

🐧

Linux

A flatpak for your own account

Download for Linux

Flatpak bundle

Install it with flatpak install --user BridgeTalk.flatpak, then start Bridge Talk from your applications menu. It finds the game's journal inside its Proton or Wine prefix and is given network access for the update check alone.
