A ship's voice for Elite Dangerous,
speaking with recordings you supply.

Bridge Talk watches the game's journal and status file while you play. When something worth saying happens, it plays one of your own recordings for that moment. It talks and never listens; it ships no audio of its own.

Who it is for

A voice for your ship.
Yours to record.

Bridge Talk gives your ship a voice that answers the game. The words are yours: it plays recordings you supply, one for each moment you have recorded.

  • Commanders playing Elite Dangerous on Windows who hold recordings they may use and want them spoken in answer to the game.
  • Anyone recording a voice for a ship who wants to see exactly which moments a set of recordings covers, then hear it before choosing it.
Who it is not for

It talks.
It never listens.

Worth knowing before you download: Bridge Talk speaks in answer to the game and nothing else.

  • Anyone wanting voice commands. There is no microphone, no speech recognition and no voice command of any kind.
  • Anyone wanting sound straight away. It ships no audio of its own, so nothing plays until it is pointed at recordings you supply.
  • Anyone hoping one line will cover for another. A moment the voice has no recording for stays silent rather than borrowing a different one.
What it does

Cast a voice.
It speaks for your ship.

Five panes run along the top of the window: Cast, Audition, Status, Missing takes and Settings. Each one does a single job.

Cast a voice

Every directory inside your recordings directory is a voice with a row of its own on the Cast pane, showing how many moments it has a recording for and how many of the recordings in its folder it uses. Press a row to cast that voice. It says something as it takes the part, unless the window is muted or the voice has no line for it.

The voice you cast is remembered, so the next start opens speaking with the same one.

See what a voice covers before you cast it

The mark at the end of every row opens the Moments spoken for dialog. It lists every moment that voice has a recording for, then every moment it was never recorded for, each of which stays quiet.

It answers for any voice, cast or not, so one can be weighed before it is cast.

How it decides what to say

One recording per moment

Where a voice holds several takes for a moment, one is chosen at random. It is never the take that moment played last time, so a line you have just heard is not repeated straight away.

Alerts come first

An alert interrupts anything less urgent. A notice waits its turn. An ambient line gives way when something is already waiting; incidental chatter gives way whenever anything is waiting or speaking.

Quiet when quiet is right

Many moments hold a minimum interval between two firings. The game restating itself within 900 milliseconds collapses into one line. A moment the voice has no recording for stays silent.

Mute when you need to

Mute silences every answer to the game. The Status pane still records each decision, so the ship never goes quiet without a reason you can read.

Every decision explained

The Status pane shows the voice that is cast, how many moments it has a recording for, the journal directory and the status file being watched. It says whether playback is live or muted and warns when no audio device was found.

Beneath that is a log of every decision with its outcome: played, queued, dropped, cooldown, duplicate or unbound. The decisions that produced no sound are logged too, so a moment that never speaks explains itself.

Hear a voice first

Choose any voice on the Audition pane, cast or not. There is one button for each part of the game; a press plays one of that voice's recordings for it at random, so pressing again can give a different take. The square beside the chooser stops a recording part way through.

An audition ignores the mute, which silences answers to the game rather than the window.

Find the takes still missing

The Missing takes pane holds the recordings directory with its Browse button, then offers every voice still missing a recording. For the one chosen it lists each missing moment with a line saying when it is heard, then the folder its audio file belongs in.

  • Open folder beside a moment opens its folder, making the folder first where it is not there yet.
  • Make folders on the Cast pane gives a new voice a folder for every moment, each already named.
  • Refresh on either pane reads the recordings directory again, so a voice filled in by hand appears without a restart.

Out of sight, still listening

The Settings pane holds the journal directory with its Browse button; it is found under your own profile until you choose one. Tick Start it when I sign in and signing in to Windows starts Bridge Talk hidden in the notification area.

Put away, it keeps watching the game and keeps speaking. The cross on the window asks rather than closes: Minimise to the notification area keeps it listening, while Quit stops it. Right click its notification-area icon for the voice to speak with, Open, Mute and Quit.

Your recordings stay yours

Nothing changed, nothing removed

Bridge Talk never changes or removes anything in the recordings directory you choose. The one thing it writes there is the empty folders you ask for, through Make folders or Open folder.

Kept through an uninstall

Uninstalling leaves your recordings where they are. That includes the Recordings folder Bridge Talk makes for itself when a voice's folders are made before any directory has been chosen.

Recording a voice

A folder for every moment.
Any file name will do.

Every moment has a folder of its own inside the voice. You never have to type a moment's name: Bridge Talk makes the folders for you.

  1. Make the folders On the Cast pane, type a name for the voice and press Make folders. That voice gets a folder for every moment, each already named. Where no recordings directory has been chosen yet, they are made in a Recordings folder of Bridge Talk's own, which becomes the recordings directory from then on.
  2. Record each take Use any program you like, such as Audacity, which is free. Save each take as WAV, MP3, FLAC or Ogg.
  3. Save it in the folder for its moment Any file name will do. A folder can hold several takes; each time that moment is spoken one of them is chosen at random.
  4. Press Refresh A voice appears on the Cast pane once one of its folders holds a recording. The Missing takes pane shows what is still left to record.
The setup program

Installs for you alone.
No administrator prompt.

The setup program installs Bridge Talk for your own Windows account, inside your local application data folder, so it never needs administrator rights. The Install screen offers a Start Menu entry, a Desktop shortcut and starting Bridge Talk when you sign in.

  • Run it again at the same version to Repair or Reinstall. Repair puts the files back and changes nothing else; Reinstall writes them again with the boxes applied as they stand.
  • A newer setup program offers to Update; an older one offers to go back a version. Your recordings and settings are untouched either way.
  • Uninstall removes the application, its shortcuts and its sign-in entry. Tick Also forget my settings to clear your chosen directories, the voice you cast, the theme and the volume as well. Your recordings are not touched.
  • Bridge Talk appears in the Windows Apps list, where Modify and Repair reopen the setup program.
  • If Bridge Talk is open, setup offers to close it before carrying on.
