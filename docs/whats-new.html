What's new

Recent releases have made Bridge Talk harder to knock over: a damaged recording, a damaged settings file or a journal briefly out of reach no longer stops the voice or loses your place. Before that it learned to tell you about a new release, kept to one running copy and gained a website with a page for each job. Earlier releases brought plugins as a third kind of voice, a Linux flatpak, the Chatter pane for choosing which moments are spoken and the first release's 28 ready-made voices.

v1.7.0

Damaged files no longer stop the voice

  • A recording whose file describes itself wrongly, stating no sample rate or claiming to run for more than ten minutes, could stop the scan of your recordings or end playback. It is now set aside before any of it is read; the scan goes on and Bridge Talk keeps playing
  • A recording that makes the decoder fail is passed over the same way, with the reason written to the log
  • A settings file that cannot be understood is kept beside the new one with .damaged added to its name, so fresh settings never overwrite what was there; one that cannot be read at all is left alone and a change you make is refused with the reason
  • A journal briefly out of reach no longer makes Bridge Talk speak earlier lines again: it keeps its place, always follows the newest journal under either form of name the game has used and plays the last lines of the old journal before moving to a new one
  • A journal folder that cannot be read is reported in the log once for each new reason rather than four times a second
  • Plugins are refused for the true reason: two voices under one id, a failure while stating the version or an answer claiming more entries than it could hold
v1.6.0

A website with a page for each job

  • Bridge Talk itself is unchanged; this release is about the website and the documents beside the code
  • The site was one long page and is now four: Home, Features, Why and Download, linked from a bar across the top and again from the foot of every page
  • Each page links its stylesheet by a fingerprint of its content, so a browser never draws a new page in an old style
  • The README, the website, the plugin guide and the developer documents now describe Linux as it is: no notification-area icon, closing the window quits and a start at sign-in opens the window
  • For developers, DECISIONS-TRADEOFFS.md sets out the decisions Bridge Talk rests on with what each one gains and costs
v1.5.0

It tells you when there is a new release

  • A few seconds after it starts and once a day while it runs, Bridge Talk asks GitHub for its latest published release; when a newer one is out it offers Download, Skip this version or Later
  • Download opens the right file for your computer in your browser: the setup program on Windows, the flatpak on Linux
  • Help, then Check for updates asks at once and reports whatever it found, a skipped release included
  • The check is the one network request Bridge Talk makes and sends nothing about you, your computer or the game; when it cannot reach GitHub it stays silent unless you asked
  • Starting Bridge Talk while it is already running brings back the running copy's window instead of a second copy speaking over the first
  • On Linux the flatpak is granted network access for the update check alone; reinstall from the new bundle for the check to reach GitHub
v1.4.2

A new donation page

  • The Donate button now opens a new PayPal page that suggests £5 and lets you give any amount you choose; nothing else has changed
v1.4.1

Chatter shows what can be pressed

  • Each category name in Chatter's header now carries an arrow pointing down at the list, since pressing it moves the list to that category
  • Each heading in the list carries a mark that points down while its category is open and at its words while it is collapsed
  • The help guide's Chatter section now says what pressing either one does
v1.4.0

Plugin voices on the Cast and Audition panes

  • Bridge Talk speaks version 2 of the plugin interface and loads no other; a version 1 plugin is refused with the file and both versions named in the run log
  • Version 2 lets a plugin arrange its voices under groups of its own naming and point at a recording that is a span of a larger file, read where it stands without being copied
  • Each plugin's voices stand in a section of their own on the Cast pane, headed by the plugin's name, above the machine voices
  • The Audition pane offers every plugin voice that can speak, in the same order as the Cast pane, so you can hear one before casting it
  • The cast voice now keeps its place in its panel, shown disabled, so every voice stays where you would look for it
  • The licence gains a plugin exception: a plugin that talks to Bridge Talk only through the published interface may carry terms of its own author's choosing
v1.3.0

Plugins, Linux and a Chatter pane that is easier to find your way around

  • Plugins are a third kind of voice beside recorded and machine voices: a library file in the plugins folder offering voices whose audio is already on your machine
  • Nothing a plugin does can stop Bridge Talk starting; one that will not load is passed over and named in the run log. A plugin runs with your own rights, so only put in one whose author you trust
  • PLUGINS-GUIDE.md is the contract for writing a plugin, with a worked example in C
  • Bridge Talk now builds for Linux as a flatpak with recorded voices, all 28 machine voices and plugins; it finds the journal inside the game's Proton or Wine prefix
  • The Audition pane plays only moments switched on in Chatter, grouped under Chatter's categories, so it never plays a line the ship would not say
  • Each category name in Chatter's header moves the list to it, each heading collapses its category and the moments stand in three columns, so far less scrolling is needed
  • Category headings stand in a lavender pill; the line under each title is cyan so it reads apart from the headings
  • A fault in the part that watches the game no longer closes the window: the Status pane says Bridge Talk has stopped reacting and should be started again
  • The setup window's error screen now offers Close
  • The site offers the Linux flatpak beside the Windows setup program and compares Bridge Talk with EDCoPilot as well
v1.2.0

Chatter: choose which moments are spoken

  • A new Chatter pane lists all 262 moments the game raises under twelve categories, each with a switch
  • A moment switched off stays quiet whichever voice is cast and holds nothing back, so switching it on again lets the next one be heard straight away; the Status pane records each one as off so a silence still explains itself
  • Switch all on, Switch all off and a switch for each category stay in view while the list scrolls; anything that changes more than one moment asks first, naming how many
  • The switches belong to no voice and are kept for the next start
  • Station traffic (docking answers, welcomes and no fire zone notices) is a moment of its own, so it can be switched off while other messages are still spoken
  • The site now carries a picture card for any service that shows one when a link is shared
v1.1.1

A fix for auditioning with no voice cast

  • Bridge Talk no longer closes when a line on the Audition pane finishes while no voice is cast
v1.1.0

Pirates get a reaction; install where you like

  • The ship's voice now speaks when a pirate arrives, scans your cargo, loses interest in it, starts an interdiction or declares its attack, whatever words the game chose
  • A recorded voice lists these six new moments on the Missing takes pane until they are recorded
  • Setup can install into a folder of your choosing, always inside a BridgeTalk folder of its own so uninstalling takes nothing else with it
  • Setup refuses a folder that already holds other files or that your account cannot write to, saying why before anything is written
v1.0.0

The first release: a ship's voice for Elite Dangerous

  • 28 machine voices in British and American English, female and male, make every line on your own machine; nothing is downloaded and nothing is sent anywhere
  • Every moment has three lines written for it; a newly cast machine voice speaks within five seconds
  • Follows the game's journal and status file, knowing 256 moments each named in the game's own words
  • Decides what gets said: an alert cuts in over anything less urgent, a notice waits its turn and an idle remark gives way
  • Record a voice of your own: Make folders gives every moment a folder already named; Missing takes lists what is left to record with a button to open each folder
  • Plays WAV, MP3, FLAC and Ogg recordings, picking one of several takes at random
  • The Status pane logs every decision with its reason, including those that produced no sound
  • Lives in the notification area, can start when you sign in to Windows and talks without ever listening: no microphone and no voice commands
  • A setup program of its own installs for your account only, so Windows never asks for administrator rights; uninstalling never touches your recordings
